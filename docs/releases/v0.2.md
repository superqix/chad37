# Chad37 0.2

Knobs that keep up with you, and an installer that runs in your browser.

**To install or update:** open the **[web installer](https://superqix.github.io/chad37/)** in Chrome or Edge, plug
the keyboard in by USB, and press **Find my keyboard**, then **Install**. It finds your model, picks its package and
checks it before writing; nothing to set up. Prefer the command line? Download `fm1_install.py` and your model's package
below, and follow the [install guide](https://github.com/superqix/chad37/blob/main/docs/install.md).

**Updating from 0.1 keeps your presets, chord banks and settings.** Coming from M-Vave's firmware, the first install
clears the stock settings: write down your knob and pad assignments first.

| Your keyboard | Package | Status |
| :--- | :--- | :--- |
| SMK-37 Elite | `chad37-smk37-elite-0.2.fwsc` | In daily use |
| SMK-37 Pro | `chad37-smk37-0.2.fwsc` | Tested by a user |
| MKE-P37 | `chad37-smk37-mke-0.2.fwsc` | Never installed: experimental |

The [user guide](https://superqix.github.io/chad37/manual/) covers every control, mode and setting. You can return
to M-Vave's firmware at any time from [open.m-vave.com](https://open.m-vave.com).

## What's new

- **Knob acceleration, on by default.** Turn a knob slowly and it moves one step per click, for fine adjustments;
  spin it and it speeds up smoothly, so a quick spin sweeps 0–127 in about a dozen clicks. The first click after a
  pause or a change of direction always moves one. In 0.1 a full sweep took 127 clicks.
- **KNOB SPEED setting.** On the Hardware Setup page (GLOBE twice), K7 picks **ACCEL** (the default) or a fixed
  **X1**, **X2**, **X4** or **X8** steps per click. It applies to every knob that sends a CC, in every preset. Choose
  X1 for 0.1's feel.
- **Fast spins no longer stall.** The knobs were read with a filter that, past about 50–80 clicks a second, missed
  almost every click, so spinning hard moved them slower than turning gently. Every knob now keeps up, at every
  speed setting.
- **A tidier Hardware Setup page.** All its knobs are now cells in two rows (K1–K4, then K5's volume, K6 pad
  minimum, K7 knob speed, and K8 free for later), with the pedal and note diagnostics along the bottom.
- **The web installer, and the user guide on the web.** No Python needed. If an install is cut off part way, press
  **Find my keyboard** again and it finishes. The [user guide](https://superqix.github.io/chad37/manual/) is now a
  page on the same site.
