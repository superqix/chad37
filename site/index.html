Chad37 {{VERSION}}

Chord-pad MIDI controller firmware for the M-Vave SMK-37

Install from your browser

This browser can't install it. Open this page in Chrome or Edge on Windows, macOS, Linux or Android. Safari, Firefox and iPhone/iPad don't allow it.

  1. Plug the SMK-37 into this computer with a USB data cable and switch it on.
  2. Quit everything that uses the keyboard: your DAW, synth apps, M-Vave's MIDI Suite, other browser tabs.
  3. Press Find my keyboard. The browser asks to control MIDI devices: allow it.
  4. Check the model it found, then press Install. Don't unplug the keyboard while it writes (a minute or two).

Details

  


  

    
Before the first install

    
The first install clears the stock firmware's settings, such as your knob and pad MIDI
      assignments. Write them down or take photos of them first. Your calibration (keys, wheels, pads) is kept. Updating
      from one Chad37 to a newer one keeps your presets, chord banks and settings.

If something goes wrong

    

      
What you seeWhat to do

      
        
Keyboard not foundQuit every program using the keyboard, check the cable carries data, and
          try again. On Windows, only one program at a time can use a MIDI device.

        
MIDI wasn't allowedClick the icon at the left of the address bar, allow MIDI devices, and
          reload the page.

        
It stopped part way (cable out, computer asleep)Plug back in and press Find my keyboard
          again. The keyboard waits in update mode, even after being switched off, and the page finishes the
          install.

        
The computer still shows the old nameUnplug the keyboard and plug it back in. On Windows,
          the old name can stay until you remove the device in Device Manager.
